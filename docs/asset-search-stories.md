# Keepstack 素材检索：User Stories

以题目基线 `3aa137c` 和集成分支对照。US-02 至 US-06 对应题目功能与交付。US-01、US-07 至 US-10 记录前置修复、已扩充的流程及同流程里的既有能力。每条区分自动化、浏览器实测和仍待验证的边界。[题目 README](../README.md) · [复现与 CI](../SUBMISSION.md)

## US-01 登录、退出和角色

- **故事：** 作为已创建账号的用户，我能用同一个登录表单进入对应权限的工作区，退出后可换另一个账号。
- **验收与状态：** 四种角色均通过 `8011` 同浏览器真实表单实测。右上角显示当前用户名和角色；退出清空本地会话与管理页旧内容。用下表的 seed 账号复现。
- **通过的边界：** 未登录和无权限的受保护操作分别返回 401 和 403；前端按角色展示入口，后端独立鉴权。错误密码提示 `Invalid credentials`；429 有限流提示；500 有通用失败提示。会话过期清理界面。单元测试覆盖密码哈希、令牌校验及限流期满，Playwright 覆盖错误密码、模拟 429/500、退出和重登。实际磁盘写满导致过一次 500，清理缓存后在 `8011` 登录、退出、重登均通过。
- **边界与限制：** 退出清除当前浏览器令牌，沿用既有令牌有效期。Dashboard 入口只向 admin 显示，统计 API 对所有已登录角色开放。被禁用的账户、不同浏览器会话的组合这轮未单独重测。

| 本地演示账号 | 密码 | 可见操作 |
| --- | --- | --- |
| `viewer` | `demo1234` | 搜索、排序、分页、导出 CSV、浏览集合、读取描述、下载原文件 |
| `contributor` | `demo1234` | viewer 的操作，另可上传、编辑素材、创建分享链接、新建集合、编辑描述和管理集合成员 |
| `curator`（editor） | `demo1234` | contributor 的操作，另可删除素材和集合 |
| `admin` | `admin` | editor 的操作，另有 Dashboard、完整性检查、Users、Audit log |

## US-02 组合筛选

- **故事：** 作为内容运营，我能在选定集合里搜索 `harbor`，只看同时带 `approved` 和 `campaign`、不带 `internal` 的素材。
- **验收：** 沿用现有 FTS 字段和分词，空白关键词不限制；可选一个集合或不限制。包含标签须全部命中，排除标签命中任一个即排除。条件与素材类型取交集，仅返回 `active`。标签按完整名称和现有大小写规则匹配；重复不改变结果，包含与排除同名则无结果。页面显示生效条件，支持修改和清除；选项统计不得误标为当前匹配总数。
- **状态：** 已通过。Library 的集合、包含标签和排除标签共用可搜索、可翻页的选择器样式。集合单选，支持 All collections，条件即时生效和单独移除。语义搜索入口隐藏。
- **验证：** pytest 生成正例、缺包含标签、命中任一排除标签、标签前缀相同、集合外、类型不同及非 `active` 的素材，按 UUID 断言结果；覆盖空白关键词、大小写、重复及冲突。Playwright 在 Library 组合、修改、清除条件并核对结果。
- **边界：** 有筛选且零匹配时会提示调整条件。模拟全库为空已复现 viewer 会看到 `Click Upload to get started`，但它没有上传入口。此文案待修，筛选结果本身正确。FTS 字段还包括标题、文件名、替代文本、标签和已索引的元数据／自定义字段；集合描述是展示信息。

## US-03 稳定排序与分页

- **故事：** 作为内容运营，我能按创建时间升序或降序浏览命中素材，不漏看或重复看见同一条。
- **验收：** 有关键词时也遵守创建时间排序。提供上一页、下一页、匹配总数，页大小固定。数据不变时，同创建时间的素材也不会跨页重复或遗漏。改筛选或排序回到第一页，旧请求晚返回不能覆盖最新结果。空结果、加载失败、非法分页参数及特殊字符输入都有明确行为。
- **状态：** 已通过。每页 12 条；创建时间相同按 ID 排序。旧响应不覆盖最新条件，加载失败可重试。
- **验证与边界：** pytest 拼接三页 UUID，验证升降序和相同创建时间；非法参数返回 422，特殊字符和中文请求返回 200。Playwright 检查首页／末页的禁用按钮，第二页换筛选或排序回到首页。旧请求成功返回非空结果也不会覆盖更新的零结果。模拟 500 后旧卡片消失，CSV 入口禁用，重试能恢复。数据同时变化时按当前数据重新分页；无跨请求快照。

## US-04 导出全部匹配素材

- **故事：** 作为内容运营，我能从当前 Library 下载全部命中素材的信息清单。
- **验收：** CSV 应用当前全部筛选（含素材类型）与排序，不受当前页限制。至少含 `uuid`、`title`、`description`、`filename`、`media_type`、`tags`、`created_at`，交付说明注明多标签格式。中文、逗号、引号、换行可无损解析，零结果仍输出表头。复用登录鉴权，支持页面下载和失败提示；不包含素材文件。
- **状态：** 已通过。在任一页均导出全部匹配行；原文件下载保留在详情。标签列使用 JSON 数组。
- **验证与边界：** pytest 对比两种排序下全量 CSV 与各页 UUID，含 207 条、类型、含中文和逗号／引号／换行的标题与描述、零结果仅表头、无会话 401。Playwright 在末页下载真实文件，导出途中换搜索仍下载点击时的筛选；500 有失败提示且可重试。极大导出尚无容量或性能压测，浏览器会缓冲 CSV。

## US-05 编辑后查询和导出一致

- **故事：** 作为内容运营，我更新标题、描述或标签后，下一次查询和导出能读到最新数据。
- **验收：** 使用现有详情入口保存元数据、增删标签后，后续查询的内容及匹配资格正确更新，后续 CSV 的行和字段与查询一致。不要求实时订阅或跨请求快照。
- **状态：** 已通过。Library 与集合共用详情抽屉，元数据、标签和集合成员关系使用同一草稿和 Save changes。保存失败保留草稿。测试覆盖特殊标签名、事务回滚、增删成员及保存后的查询和 CSV。
- **验证与边界：** pytest 用新旧关键词、标签加入／移除、带斜杠／引号／逗号的标签校验查询和 CSV，验证非法输入及重建索引失败时回滚。Playwright 验证两个选择器搜索、翻页、跨搜索多选、已有项禁用，`Add selected` 暂存，保存前后读 API 对比。保存失败保留输入，重试成功；历史浏览器实测确认保存不跳顶。两个编辑者同时修改同一素材时未实现版本冲突提示。

## US-06 可复现交付

- **故事：** 作为评审，我能从 Fork 的明确提交复现运行、测试和使用流程。
- **验收：** 保留基线和真实开发历史；交付可访问的 Fork、分支和完整 SHA。提供关键行为的自动化测试和可复现数据，不提交数据库、上传文件、凭据或虚拟环境。`SUBMISSION.md` 须记录运行、验证、实测结果、取舍、限制和未完成项。
- **状态：** 已提供搜索场景生成器和交付说明；集成分支的 Python 3.10、3.12 CI 已验证通过。
- **验证与边界：** 从干净 checkout 安装 `.[dev]`、用 seed 生成数据、启动应用、运行 pytest 和浏览器流程。确认 Fork 公开，Git 跟踪文件没有本地数据库、虚拟环境或上传目录。CI 使用 Python 3.10／3.12，浏览器用独立 Chromium job，失败留存 trace 和截图。CLIP 模型用例在缺模型的 CI 跳过。用 [SUBMISSION](../SUBMISSION.md) 核对代码提交、CI 和 Draft PR；PR 保持 Draft 等用户试用。

## US-07 集合成员和描述

- **故事：** 作为运营，我能创建集合、直接浏览成员、从 Library 批量加入素材，并在任一素材详情用一次保存管理所属集合。
- **验收与状态：** 已实现空集合、去重、删除集合、跨页添加素材及详情内增删成员。新建可填写可选描述，集合内显示在图片上方，可编辑和清空。viewer 能读，contributor 及以上能编辑。Collections 专注成员浏览；需筛选或导出时到 Library 选集合。
- **通过的边界：** pytest 覆盖重名、重复加入、非活跃或已失效的候选导致批次回滚、集合删除及移出后原文件仍可下载。Playwright 覆盖新集合可立即选中、集合选择器搜索和翻页、跨页添加、移出末页最后一项、成员修改后 Library 与 CSV 同步、删除集合后选项消失并移除生效条件。描述中文和换行、取消、失败保留草稿、清空和刷新持久性也已覆盖。
- **待验证：** 两个浏览器同时编辑集合描述、正在分页时另一会话删除集合。无跨浏览器实时推送。

## US-08 上传、去重与重试

- **故事：** 作为有上传权限的用户，我能知道每个文件的上传状态、失败原因和批次结果。
- **验收与状态：** 已实现英文 `Queued`、`Uploading…`、`Uploaded`、`Already exists`、`Failed`、单文件 Retry 和批次汇总。新批次清空旧记录。重复根据文件内容的 SHA-256 判断；换文件名仍会重复，同名不同内容可上传。
- **通过的边界：** pytest 覆盖大小临界值、零字节、损坏光栅图、改名后的相同内容、同名不同内容和混合批次。Playwright 验证混合状态、上传后 Audit 更新、模拟一个文件网络中断时下一文件继续和 Retry 成功。支持 CSV 等非图片素材，每文件默认最多 1024 MiB。
- **边界与待验证：** 关上传窗口不取消已经开始的请求。没有上传百分比或断点续传。关窗再打开、并发上传同一内容和多批次容量未逐项专项复测。

## US-09 素材详情、原文件和保管字段

- **故事：** 作为读者，我能查看素材详情并下载原文件；有编辑权限时可维护描述、替代文本、作者、权利和留存日期。
- **验收与状态：** 已修复原文件下载鉴权，Library 和 Collections 共用详情。保留预览、元数据、Dublin Core、版本展示和已有 Similar assets。留存日期可填有效日期或清空，只作元数据。
- **通过的边界：** `8011` 用 viewer 在真实详情下载成功。pytest 覆盖不存在的日期、闰日及清空、Dublin Core／XMP 映射、完整性与回收部分逻辑。原文件丢失由 API 返回 410。
- **已复现问题与范围：** 模拟详情元数据请求 500，抽屉停在 `Loading...`，没有重试入口。Similar assets 按现有向量的余弦相似度排列；装有 CLIP 时优先用图片向量，默认本地演示可回退到文本特征。检索相关性与留存自动执行均在题目范围外。

## US-10 分享、审计与管理

- **故事：** 作为有权限的成员，我能创建分享链接；作为管理员，我能查操作记录、查看统计和添加用户。
- **验收与状态：** 保留现有分享、Dashboard、完整性检查、Users 和 Audit log。修复创建分享和用户的 JSON 请求方法。新增集合描述更新和标签／集合成员移除的审计记录，对应变更和该记录同事务写入。上传批次结束后，如果 Audit 页打开会自动重查。
- **通过的边界：** pytest 覆盖非法过期时间、明确时区的过期链接、撤销、标签和成员移除审计。Playwright 检查上传成功的记录出现，重复文件不产生新上传记录。`8011` 的 Users 和 Audit 对 admin 返回 200、对另外三角色返回 403。
- **已知边界：** 分享过期和撤销只验证 API 路径。模拟创建分享、删除素材、Users 和 Dashboard 的接口返回 500 时，浏览器产生未捕获错误，应用框架仍在，但缺少提示。按现有代码，剪贴板拒绝时仍会显示 `Share link copied`。Users 目前用原生输入弹窗创建用户，没有改角色或禁用账户的前端表单。统一弹窗样式待定。

## 已确认的 UI 设计

- **筛选布局：** Library 内集中显示关键词、集合、素材类型与标签。Collections 只显示成员和管理操作，不重复提供搜索或 CSV；返回 Library 时保留原筛选。
- **标签交互：** 两个可搜索选择器分别用 ＋ / − 和文字说明「必须全部包含」「任一命中即排除」，可用 Previous / Next 翻页。已选条件始终可见，改动即时生效；刚保存的标签优先出现在第一页。
- **素材详情：** Add tags 和 Add collections 共用可搜索、可翻页的多选选择器。选择后进入草稿，随编辑表单统一保存。
- **分页和导出：** 每页 12 条、默认最新优先。导出按钮显示全部匹配数量；详情的原文件下载与清单导出是不同入口。
